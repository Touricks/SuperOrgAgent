# 搭建手册：模板空间和项目空间

飞书项目的类型、字段、流程、表单、角色、详情页和视图，命令行建不了，只能在网页上做。这份手册给研究员自己照着点，也给能操作浏览器或飞书桌面端的会话代点。界面按 2026 年 10 月的飞书项目写，位置对不上时以核对命令的结果为准。下面的命令里 `$PLUGIN` 指插件根目录。

空间分两层：模板空间每个实验室或企业搭一次；每个项目从模板复制出自己的空间。

## 先说规矩

- 代点之前先请研究员确认一次：这次要在哪个空间做哪几段。
- 只建不删。删空间、删类型、删字段都由研究员本人做。
- 遇到升级提示、付费弹窗、权限申请或没见过的对话框，停下来问研究员。升级提示按 Esc 关掉，不点“联系销售”。
- 每做完一段跑一次核对命令，对上了再往下走。
- 建空间要有飞书项目里建空间的权限。建空间的人就是空间管理员，配置类型、字段和流程都要管理员。

## 搭模板空间

模板空间默认叫 std_template，任务文件的 `feishu.template_space` 可以改名。它只当复制源：只放结构，不放工作项，不跑项目，也不建条件视图，因为复制时视图不会带过去。项目上的临时改动只改项目空间，不要改进模板，不然以后复制的项目都会带上。

1. **建空间。** 在飞书项目里新建一个空间，名称填 std_template。核对：`meegle project search --project-key std_template` 能查到它。
2. **拿清单。** 跑 `python3 -I "$PLUGIN/scripts/setup.py" template --live`。它列出每种类型要有的状态、流转、流转表单、角色和字段，下面几步都照这份清单做。
3. **建六种类型。** 在“空间配置 > 工作项管理”里新建类型：名称照清单写；流程模式选“状态模式”；系统标识可以填清单里的英文标识，提示已被占用就换一个，绑定不靠它。类型卡片的“…”菜单里只有“禁用”，类型不能复制，六种都要单独建。用不上的系统类型（比如需求、缺陷）可以在这个菜单里禁用，不禁用也不影响插件。
4. **加角色。** 每种类型都加一个“研究员”角色，下一步设状态授权要用到它。
5. **建字段。** 照清单给每种类型建自定义字段，名字、类型和选项都照抄。
   - 序列、发出方、主文档、截止时间、规格版本、评测集版本是六种类型共有的字段，来源工作项也有四种类型要用。这些字段在一个类型上建好，从字段右侧“…”菜单选“复制至其他工作项”；新建链接、日期这类字段时，表单里也有“批量创建至其他工作项”。两种做法都连字段 ID 一起复制。
   - “所属项目”是关联字段，除了项目，其余五种类型各建一个：先建一条从这个类型指向“项目”的关联关系，再用它建字段。关联字段不能批量复制。
   - 跨序列需求的发起序列、承接序列，选项和“序列”一样：用“复用已有字段的选项”，来源选“序列”，复用方式选“复制出一份数据”。
6. **建状态流。** 新类型的默认流程里有未开始、进行中、已结束和已终止四个状态。
   - 前三个改名复用，其余照清单新增。清单里列在第一个的是起始状态；没有流转出去的状态（比如项目的已结项、同序列需求的归档）类型设成“完成状态”。
   - 删掉清单里没有的流转，补上清单里有的。
   - 每个状态都要设“状态授权角色”，这一项必填，全部设成“研究员”。保存前在表格的授权角色一列逐个核对，显示“-”的是没生效，要补设。
   - “已终止”是状态模式自带的，不要删。
7. **配流转表单。** 照清单“流转表单必填”一行逐条配。
   - 在类型的“流程管理”里打开流程。流程表“流转表单”一列，每条流转旁边有“配置表单”，点开就是表单设计器。
   - 在左侧资源库搜字段名，把字段拖进中间的表单区（只认拖放，做法见“代点时要注意”）；选中它，右侧“是否必填”选“必填”。不该在表单里的字段，选中后点右上角的垃圾桶，这只是移出表单，字段本身还在。
   - 点“确认”只是暂存。回到流程页再点“保存流程”，看到“保存成功”才算存上；“保存流程”是灰的，说明没有要存的改动。
   - 流程表里的“配置表单·N个字段”只能核对字段数，看不出必填。保存以后重新打开表单，看字段名旁边有没有红色星号。
8. **配详情页。** 在类型的“页面布局”里改“详情页布局”。
   - “基本信息”默认只有“名称”，字段放进去人在页面上才看得到。把所属项目、序列、发出方、来源工作项、负责会话、主文档、截止时间按这个顺序放进同一个分组，排在“名称”后面，类型没有的字段跳过。六种类型放的是：
     - 项目：序列、发出方、主文档、截止时间。
     - 同序列需求：所属项目、序列、发出方、来源工作项、负责会话、主文档、截止时间。
     - 跨序列需求、送审、决策：所属项目、序列、发出方、来源工作项、主文档、截止时间。
     - 反馈：所属项目、序列、发出方、主文档、截止时间。
   - 在左侧资源库搜字段名，拖到最后一行上，出现蓝色插入线再松开，做法见“代点时要注意”。搜“序列”会连带出“跨序列需求类型”“承接序列”“发起序列”这些名字里带“序列”的字段，拖之前看清名字。放错了就选中那一行，点右侧面板右上角的垃圾桶，这只是移出布局，字段本身还在。
   - 项目的详情页加一个标签页“同序列需求”，放“工作项视图”控件：数据源选本空间的同序列需求，数据集选“部分数据可见”，范围条件写“所属项目 存在选项属于 当前值”。“视图”控件要旗舰版，不用它。
   - 页面布局没有保存按钮，每一步自动保存，看到“更新成功”。
9. **核对。** 再跑 `setup.py template --live`，直到最后一行是“可以当模板”；它也查模板里有没有工作项。流转、流转表单和详情页脚本读不到，对照清单在网页上再看一遍。多行文本在字段字典里显示成 text，和单行文本分不出来，建的时候在网页上看清字段类型。

插件规则以后改了，先在模板里改，再跑一次 `setup.py template --live`。已经复制出去的项目空间不会跟着变，各自照绑定预览的清单补。

## 从模板复制项目空间

每个项目一个空间，名字写在任务文件的 `feishu.meegle_space`。

1. 在模板空间的“空间配置 > 空间信息 > 分享空间配置”生成链接。有效期和密码按需要选，链接只在企业内可用。
2. 打开链接，点“去创建空间”。名称填任务文件里的空间名，域名用系统给的，一分钟内建成。企业里已经有同名空间的（比如要替换的旧空间），按名字会查到两个，绑定会停下：任务文件改写新空间的 simple_name，或者请研究员先删掉旧空间，删空间只能研究员本人做。已经绑定过旧空间的项目，照 `feishu-space.md` 的“换空间”一节做。
3. 建好以后，在分享记录里取消这条链接。
4. 核对：`python3 -I "$PLUGIN/scripts/setup.py" feishu --target <项目目录> --live`。“要处理的问题”里不该有类型和字段的问题，剩下的是条件视图和读回。

复制会带过去的：类型、字段和选项、角色、状态、流转、流转表单、详情页布局，以及系统类型的停用状态，类型和字段的标识不变。流程模板 ID 会变，绑定时读回。条件视图和空间置顶不会带过去。跨企业复制没有验证过；行业专版和其他版本之间、飞书项目和 Meegle 之间不互通。

## 在项目空间补视图和置顶

六个条件视图是给研究员看的。agent 查台账用 MQL，不依赖视图，可以先不建，需要时再补。每个视图的条件、排序和显示列见 `feishu-space.md` 的“六个条件视图”。

1. 在对应类型的列表页打开“视图列表”标签，新建视图。视图类型默认就是条件视图，可见范围选公开，照表填条件和排序。
2. 新建对话框里的“添加至导航”只能选“个人”。表里标了置顶的四个，建好以后在左侧“空间置顶”的“+”里选“添加现有”，勾上。
3. 显示列在视图右上角“…”→“设置视图展示”里改，改完标题旁出现“存在本地变更”，点“保存”才对所有人生效。还没有工作项时表格不出表头，列配不了，等有了第一条工作项再配。
4. 核对：`setup.py feishu --target <项目目录> --live` 打印的“条件视图”一节，现状应当是“已有”。脚本查不到视图是否置顶，自己看一眼。

## 代点时要注意

- 表单设计器、详情页布局和表格列只认 HTML5 拖放，模拟的鼠标拖动和双击都加不进字段。有两种做法：
  - 在页面里用脚本依次派发 dragstart、dragenter、dragover、drop、dragend；中间的 dragover 不能少，少了控件保存后会消失。放完先刷新，确认控件还在，再配数据源。只有允许用页面脚本改界面的浏览器工具才能这么做；手上的脚本工具只许用来调试的，用下一种做法。
  - 在飞书桌面端由会话接管整个屏幕，用真实的鼠标拖：在资源库的字段上按下，分几步移到表单里已有的一行上，空表单就移到空分组里；停住，等出现蓝色插入线（空表单是整个分组变蓝）再松开。落在表单行下方的空白处不生效，不接管屏幕的后台拖动也加不进去。接管前先请研究员确认；接管期间研究员别碰键盘和鼠标，不然按键会落进飞书。
- 弹窗的高度会变，按钮跟着挪位置。每次点之前重新截图定位，不沿用上一次的坐标；窗口尺寸变了也一样。
- 点错了先截图核对。“保存修改”按钮是灰的，说明没有改动，点取消退出。
- 记下每一段做了什么、核对结果是什么，交给研究员看。
