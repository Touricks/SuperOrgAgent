先读项目 `spec/requirements.md`、`spec/spec.md`、`spec/eval-protocol.md` 及有关工作项。按 `../../skills/spec/references/questions.md` 补足会影响决策的问题，不把旧的一句话描述当作已确定的评测合同。

产品 +2 负责需求，算法 +2 负责规格，质量 +2 负责独立评测。写清目标用户、基线、成功判据、资源预算、可改范围、数据划分和停止条件。评测保护路径只读，修改要研究员决定；变更通过决策包登记，再由维护流程更新相关配置。

起草内容走本地任务包；工作项和任务包默认由书记员登记，明确委派可代办。独立正文按项目 AGENTS.md 和 `.agent-org/operations/publishing.md` 发布。会话工具按 entry 技能，脚本位于 `.agent-org/bin/`。
