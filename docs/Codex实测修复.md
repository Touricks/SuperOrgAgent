## 模板视图复制实验

在 std_template 的“同序列需求”下新建公开条件视图“阻塞”，保存“状态属于阻塞”的条件并加入空间置顶。使用新的空间配置分享创建 agent-org-view-copy-1103，随后撤销本次临时分享。

复制后的类型标识与源模板一致。API 查询源模板返回“阻塞”，对新空间使用相同类型标识和关键词返回空列表；新空间查询“全部”返回系统预置视图。网页“全部视图”页只列系统预置的“终止任务包池”和“全部”，与 API 结果一致。

结论限定于本次同企业“分享空间配置”路径：自定义视图未随配置复制。按照用户要求，初始化完全不承担视图创建，也不以 computer-use 补建作为备用步骤。Agent 继续通过台账条件查询读取决策、阻塞、待验收等状态。

原始回读及源模板、复制空间、分享撤销截图保存在本地 `tests/local-results/view-copy-2026-11-03/`，不进入插件安装包和 Git 发布。模板中的实验视图及复制空间保留，便于复查。

## 五分钟配置

配置范围保持为三处可用：飞书项目结构绑定、完整知识节点、默认 21 个角色聊天，以及关联项目与文档的最小立项。完整派活、交付、质量验收和恢复检查另行计时。

已实施的缩时措施：字段读取最多 4 路并发；知识节点在单次加锁创建中按父节点共用列表结果，29 个节点只需 4 组列表查询；先开书记员，余下会话分批启动，允许知识节点准备与其他角色开局并行。角色数量、知识节点和身份验证要求没有删减。

新复制空间的字段字典导出实测耗时 **3.88 秒**，包含 8 个启用类型的字段与角色，其中 6 个为插件业务类型。此数据只衡量元数据读取，不能代替完整配置耗时。

codex_onboarding.py 从下载后开始安装配置时记录起点；依赖安装、认证、复制空间、人工信任等待和最终检查都计入 300 秒，中断不重置。finish 同时保存本地检查结果，live_acceptance 始终要求补充当次远端回读。

**尚未满足的最终验收：全新用户在 300 秒内完成三处配置。** 本轮未新开 21 个聊天，也未重新执行完整业务协同。当前模板分享页面仅提供企业内复制；若“任何新用户”包括其他企业账号，还需验证可获取同等模板的分发路径。当前已登录账号的速度不作为新用户验收结果。
